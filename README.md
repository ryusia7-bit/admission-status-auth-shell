# 입퇴원현황(정신건강팀) G0 로그인 껍데기

GitHub Pages에서 제공하는 **가상 G0 로그인 화면**입니다. 이 저장소는 환자기록을 처리하지 않으며, 목록·검색·저장 기능도 포함하지 않습니다.

## 공개 저장소에 넣지 않는 정보

- 환자 정보, 마스터·병원 스프레드시트 ID, 기관·병원 담당자 이메일
- OAuth 비밀값, Apps Script 속성, 실행 로그, 접근권한표
- 실제 Apps Script 주소 또는 운영 설정

화면은 배포 시점에 공개 가능한 OAuth 클라이언트 ID와 고정된 시험용 Apps Script 주소를 별도 검토 후 주입하도록 설계되어 있습니다. 설정이 없거나 올바르지 않으면 로그인 토큰을 전달하지 않고 실패 닫힘 상태로 멈춥니다.

## 현재 검증 범위

`node --test auth-shell.test.mjs`는 공개 금지 정보·와일드카드 메시지 출처·브라우저 저장소 사용·잘못된 iframe 권한을 점검합니다. 실제 Google 로그인과 Apps Script 간 인증 검증은 별도 G0 승인 후에만 수행합니다.
